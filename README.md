# Sistema de Auditoría de Inventario

Proyecto desarrollado en Python para auditar inventarios y calcular automáticamente la cantidad de artículos que deben ser reabastecidos según el stock mínimo requerido.

## Funcionalidades
- Uso de matrices
- Funciones en Python
- Validación de stock
- Generación de reporte automático
